# Features

Talaria features help you monitor, debug, and improve your applications:

- **[Monitors](./monitors.md)** — Check in from cron or scheduled jobs so a missed run opens an issue automatically
- **[Releases](./releases.md)** — Track deployments and associate errors with specific releases
- **[Analytics](./analytics.md)** — Track custom events and user behavior
- **[Feature flags](./feature-flags.md)** — Toggle features remotely or roll out by percentage
- **[Runtime](./runtime.md)** — Monitor server-side runtime metrics and resource usage

Browse the feature pages for implementation guides and API documentation.

Each stack will have a hub and a standard page set (install, configuration, tracing, logs, metrics, releases, fail-safe, troubleshooting). JavaScript frameworks are guides under the JavaScript platform, not a flat list of peers.

This first shell ships a rewritten [JavaScript](/sdk/javascript/) hub. Other SDK pages are still raw material in the repo (`sdk/<platform>/`) and will be rewritten in the content wave.

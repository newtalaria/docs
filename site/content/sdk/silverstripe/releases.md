---
title: Silverstripe releases
description: Attach Silverstripe events to a named release.
section: sdk
order: 116
---

Set the release (or the `TALARIA_RELEASE` / CI release convention on the page) so events attach to the build you shipped. See [Releases](/guides/releases/). CLI: `talaria releases new`, `talaria releases finalize`, and `talaria releases deploy`.

Related: [Silverstripe](/sdk/silverstripe/), [Silverstripe configuration](/sdk/silverstripe/configuration/).

The package includes a `Profiler` and optional React Router instrumentation. Whether those surfaces send data follows [project settings](/get-started/project-settings/). Enable tracing in the dashboard, keep a publishable key in `init`, and see the [browser tracing](/sdk/javascript/tracing/) notes.

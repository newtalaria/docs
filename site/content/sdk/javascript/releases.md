---
title: JavaScript releases
description: Attach JavaScript events to a named release.
section: sdk
order: 27
---

Set optional `release` in `init` so events attach to the build you shipped. Create the release and upload source maps from CI with a **secret** key — see [Releases](/guides/releases/) and [Source maps](/guides/source-maps/). CLI: `talaria releases new`, `talaria releases finalize`, and `talaria releases deploy`.

Related: [JavaScript](/sdk/javascript/), [JavaScript configuration](/sdk/javascript/configuration/).
